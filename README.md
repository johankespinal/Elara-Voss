# Elara Voss — experiencia musical inmersiva

Demo conceptual de web para una artista musical ficticia. Creada como muestra de **diseño web creativo, animaciones CSS y efectos interactivos** para el portafolio de Johan Espinal / Web SEO Digital.

**[Ver demostración (tras activar GitHub Pages)](https://johankespinal.github.io/Elara-Voss/)**

## Características
- Portada a pantalla completa con retrato de Elara, nubes tormentosas, luna y niebla.
- Movimiento atmosférico con CSS, destellos sutiles y parallax al mover el puntero.
- Apariciones de textos, desplazamiento suave y menú responsive.
- Álbum conceptual, discografía, historia, fechas y enlaces.
- Soporte de preferencia del sistema para reducir movimiento.
- HTML, CSS y JavaScript puros, sin backend ni dependencias de animación.

## Estructura
- `index.html` — estructura de la web
- `styles.css` — diseño y animaciones
- `app.js` — navegación y efectos interactivos
- `assets/elara-portrait.webp` — fotografía conceptual de la artista generada para el proyecto
- `assets/storm-clouds.webp` — nubes atmosféricas del diseño

## Publicación
Activa **Settings → Pages → Deploy from a branch → main → /(root)**.

## Transparencia
**Elara Voss es una cantante ficticia.** Los álbumes, las canciones y los eventos son conceptos de demostración; no hay audios, boletos ni eventos reales. Los botones de reproducción solo muestran un aviso y no reproducen música. Este proyecto sirve para mostrar diseño y animación; no representa una campaña de un artista real.
